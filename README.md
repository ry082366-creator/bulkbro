# BulkBro v4.0

## 主な変更

- クイック入力をメインに維持
- 標準種目・追加種目を分けず「種目一覧」に統一
- 一覧上では全種目を同じ削除UIで操作
  - 標準種目: 非表示（復元可能）
  - 追加種目: 一覧から削除
  - 過去のトレーニング記録は残る
- 非表示種目の管理は折りたたみ表示
- 本日入力済み種目に ✓ 表示
- 履歴削除は同日の元データをすべて削除
- 履歴編集保存時に古い同日データを日付IDの1件へ統合
- 入力画面に休憩タイマー設定
  - 初期値1分
  - OFF / 30秒 / 1分 / 1分30秒 / 2分 / 3分 / 5分
  - 種目ごとに前回設定を記憶
  - 保存時に自動開始
  - 終了時に約1秒バイブし、自動終了
  - 画面移動後も上部に残り時間を表示

## 起動

```cmd
npm install
npm run dev
```

## 公開版への反映

GitHub接続済みの既存フォルダへ中身を上書きしてから:

```cmd
git add .
git commit -m "BulkBro v4.0"
git push
```

## iPhoneの注意

Webブラウザでは、画面がバックグラウンドになっている間の振動やタイマー更新がOSに制限される場合があります。画面を開いている状態での利用を基本としています。
